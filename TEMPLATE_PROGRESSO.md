## 3. Registro das aulas

### Aula 01 — Desmistificando Git e GitHub
- **Objetivos:** Diferenciar Git de GitHub; entender por que o Git é local/offline e o GitHub é na nuvem.
- **Resultado:** Compreendeu que o Git não roda código, mas monitora o histórico de versões.

### Aula 02 — Verificação e Identidade no Git
- **Objetivos:** Checar instalação e configurar identidade do autor (`user.name` e `user.email`).
- **Comandos:** `git --version`, `git config --list`.
- **Resultado:** Git 2.50.1 confirmado e identidade global de Vlaudimir Marques validada.

### Aula 03 — Primeiro Repositório, os 3 Estados e Primeiro Commit
- **Objetivos:** Criar repositório (`git init`), usar `git status`, mover arquivos para o palco (`git add`) e gravar a versão oficial (`git commit`).
- **Experiência:** Superou com sucesso a edição no Vim (`:wq`) e registrou o primeiro commit oficial (`cdb6cef`).

### Aula 04 — Inspecionando o Histórico e Alterações
- **Objetivos:** Uso do `git diff` para inspecionar adições/remoções linha por linha e segundo commit (`e5a03aa`).

### Aula 05 — O Guarda-Costas do Projeto (.gitignore)
- **Objetivos:** Proteger o projeto contra arquivos indesejados (`.DS_Store`) e terceiro commit (`16e2f9f`).

### Aula 06 — Conexão Remota e Primeiro `git push`
- **Objetivos:** Criar repositório no GitHub, vincular local ao remoto (`git remote add origin`) e sincronizar histórico (`git push -u origin main`).
- **Resultado:** 16 objetos enviados e rastreamento upstream configurado com sucesso!
