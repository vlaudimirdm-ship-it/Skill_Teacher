# Guia de Contribuição — Skill Teacher

Obrigado pelo interesse em contribuir com o nosso projeto! Para manter o repositório organizado e com alta qualidade, seguimos os padrões abaixo:

## 1. Fluxo de Trabalho (GitHub Flow)
1. Crie uma branch a partir da `main` com um nome descritivo:
   - `feat/nome-da-funcionalidade`
   - `fix/correcao-do-bug`
   - `docs/melhoria-documentacao`
2. Faça seus commits com frequência e mensagens claras.
3. Abra um Pull Request (PR) detalhando o que foi feito.

## 2. Padrão de Commits (Conventional Commits)
Utilizamos o formato: `tipo: descrição objetiva`
- `feat:` Nova funcionalidade
- `fix:` Correção de bug
- `docs:` Alterações na documentação
- `refactor:` Melhoria de código sem alterar regra de negócio
- `chore:` Tarefas de manutenção ou configuração

## 3. Vinculação com Issues
Sempre mencione a Issue correspondente no commit ou no PR usando:
- `Closes #NUMERO` ou `Fixes #NUMERO`
